# Shaheen's Portfolio Website

This is a personal portfolio website built using [FASTN](https://fastn.com), a powerful and modern web development framework.

## 📋 Project Overview

This portfolio showcases:

- Professional experience and skills
- Projects and work samples
- Personal information and contact details

## 🚀 Getting Started

### Prerequisites

- Basic understanding of command-line tools
- Terminal/Command Prompt

### Installation

1. Install FASTN by running the following command:

```bash
source <(curl -fsSL https://fastn.com/install.sh)
```

2. Clone this repository (optional if you already have the files):

```bash
git clone https://github.com/shaheen-senpai/portfolio-fastn.git
cd portfolio-fastn
```

3. Run the development server:

```bash
fastn serve
```

4. Open your browser and navigate to:

```
http://localhost:8000
```
